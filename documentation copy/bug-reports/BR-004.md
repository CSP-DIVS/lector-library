# BR-004: Filter Chips Reset After Page Reload Causing Lost Context

Severity: Minor
Priority: Low
Component: Frontend SPA (React), Book Catalog
Environment: Local, CI E2E, Chrome 128
Affected Version: 1.0.0
Status: Open

## Summary
When a user applies multiple filters (Category + Author) and reloads the page (F5), the filter chips disappear even though the URL contains the query params. Results revert to unfiltered view.

## Steps to Reproduce
1. Navigate to Catalog.
2. Apply Category = "Science" and Author = "Asimov" filters.
3. Confirm results are filtered; observe URL includes query params.
4. Press F5 to reload the page.

## Expected Result
- On load, the SPA should parse URL params and restore filter chips and results.

## Actual Result
- Filters are cleared; results revert to default.

## Impact
- Poor UX; users lose context when sharing URLs or reloading.

## Evidence / Screenshots
![Filters lost after reload](./screenshots/BR-004.png)

## Suggested Fix
- On app init, parse URL params and hydrate filter state.
- Add E2E coverage for deep links with filters.
